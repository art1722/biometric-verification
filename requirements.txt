# Biometric QC — pinned dependencies

# Python: 3.11.x  (see README)
#   MediaPipe ships wheels for 3.9–3.12; 3.13 is NOT supported yet.
#   3.11 is the safest, most-tested choice.
#
# WHY THESE EXACT PINS (CV/ML core):
#   mediapipe 0.10.31 (latest) broke the `mp.solutions` API via a protobuf
#   incompatibility ("'MessageFactory' object has no attribute 'GetPrototype'").
#   The known-good combination that keeps `mp.solutions.face_mesh` working is
#   mediapipe 0.10.21 + protobuf 4.25.x + numpy 1.26.x. Pinning all three
#   together is the point — upgrading any one of them can re-break solutions.
